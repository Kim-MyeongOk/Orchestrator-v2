# 📖 vLLM Orchestrator Deep Agent - 사용자 이용 명세서 (User Guide)

## 1. 시스템 개요

- **시스템 소개**: 질문을 입력하면 LLM 이 웹 리서치·사고 과정을 거쳐 답변을 만들고, 그 과정을 실시간으로 화면에 흘려보내는 대화형 시스템입니다.
- **주요 제공 기능**
  - 💬 **실시간 답변 스트리밍**: 답변이 완성될 때까지 기다리지 않고 토큰 단위로 즉시 표시
  - 🧠 **생각 과정(Reasoning) 표시**: 모델이 답을 만들어가는 추론 과정을 함께 확인
  - 🗜️ **대화 요약/압축**: 대화가 길어지면 이전 내용을 자동 요약해 응답 속도를 유지
  - 🔊 **음성 읽기(TTS)**: 답변을 소리로 들을 수 있음
  - 🎙 **음성 입력(STT)**: 말한 내용을 받아 적어 입력창에 채워줌
  - 🔖 **북마크 + 메모**: 중요한 답변을 저장하고, 왜 저장했는지 메모를 남길 수 있음
  - ❝ **참조하기**: 답변의 일부를 드래그해 다음 질문의 문맥으로 함께 전달
  - 📌 **답변 다중 참조**: 이전 답변 여러 개를 우클릭으로 골라 한 번에 전달
  - 🖼 **이미지 첨부(Vision)**: 이미지를 올려 "이게 뭐야?" 처럼 그림에 대해 물어보기

## 2. 화면 구성 및 주요 인터페이스 (UI)

- **좌측 사이드바**
  - `＋ 새 채팅방` 버튼
  - **채팅방 / 북마크 탭**: 대화 목록과 저장한 답변 목록을 전환
  - **세션 설정**: 로그인 사용자, 모델 선택, 생각 정도, 개발자 모드, 세션 초기화
- **가운데 대화창**
  - 🧠 **생각 과정 표시**: 답변 전 모델의 추론 과정이 펼쳐짐
  - 💬 **답변 토큰 표시**: 최종 답변이 실시간으로 출력
  - 답변 하단 아이콘: 복사 · 🔖 북마크 · 🔊 음성 읽기
- **하단 입력창**: 📎 이미지 첨부 · 질문 입력 · 🎙 음성 입력 · 프리셋 선택 · 전송/중지

## 3. 주요 기능별 사용 방법

### 3.0. 회원가입 및 로그인

1. 로그인 화면에서 **「회원가입」 탭**을 누릅니다.
2. 사용자 ID, 비밀번호, 비밀번호 확인을 입력하고 `회원가입`을 누릅니다.
3. 가입에 성공하면 곧바로 채팅 화면으로 들어갑니다.

**이미 사용 중인 ID 를 입력한 경우**

- ID 입력칸 **바로 아래에 빨간 글씨로 「이미 등록된 유저입니다.」** 가 표시되고, 입력칸 테두리도 빨갛게 바뀝니다.
- ID 칸에 커서가 자동으로 놓이고 기존 값이 선택되어, 바로 다른 ID 를 입력할 수 있습니다.
- **ID 를 고치기 시작하면 경고가 사라집니다.** 탭을 바꿔도 사라집니다.
- 이미 본인 계정이라면 「로그인」 탭으로 옮겨 로그인하세요.

> 📌 **참고 사항**
> - 비밀번호는 **4자 이상**이어야 하며, 서버에는 해시(PBKDF2)로만 저장됩니다.
> - **이미 있는 ID 로 다시 가입해도 기존 비밀번호는 바뀌지 않습니다.** 비밀번호를 잊었다면 새 ID 로 가입해 주세요.
> - 로그인/비밀번호 오류는 어느 쪽이 틀렸는지 알려주지 않습니다 (계정 존재 여부를 감추기 위함).

---

### 3.1. 질문하기 및 실시간 답변 받기

1. 입력창에 궁금한 내용을 적고 `전송` 버튼을 누릅니다.
2. **생각 과정 보기**가 켜져 있으면, 답변에 앞서 모델의 추론 과정이 먼저 표시됩니다.
3. 이어 답변 텍스트가 실시간으로 출력됩니다.

### 3.2. 대화 세션 및 옵션 설정

- **모델**: 사이드바에서 이 채팅방에 사용할 모델을 고릅니다. (선택하지 않으면 서버 기본 모델)
- **생각 정도 (Reasoning Effort)**: `낮음` / `보통` / `높음` 중에서 답변의 깊이를 조절합니다.
- **대화 압축 안내**: 대화가 길어지면 시스템이 이전 대화를 자동으로 요약하고, 요약이 일어났다는 안내가 표시됩니다.

### 3.3. 북마크 저장 및 메모 작성

중요한 답변을 저장해 두고, 나중에 왜 저장했는지 알아볼 수 있도록 메모를 붙일 수 있습니다.

**① 답변 저장하기**
1. 저장하고 싶은 답변 하단의 **🔖 북마크 아이콘**을 누릅니다.
2. 사이드바 **「북마크」 탭**에 해당 답변이 미리보기와 함께 추가됩니다.

**② 메모 작성 / 수정하기**
1. 사이드바 **「북마크」 탭**을 엽니다.
2. 메모를 남길 항목 위에 마우스를 올리면 우측에 **✎(연필) 버튼**이 나타납니다. 이 버튼을 누릅니다.
3. 항목 안에 **입력창이 펼쳐집니다.** 내용을 입력하고 저장합니다.

| 조작 | 동작 |
|---|---|
| `저장` 버튼 또는 `Enter` | 메모를 저장합니다 |
| `Shift` + `Enter` | 줄바꿈 (여러 줄 메모 작성) |
| `취소` 버튼 또는 `Esc` | 수정을 취소하고 원래 내용으로 되돌립니다 |

4. 저장한 메모는 북마크 미리보기 아래에 **노란 세로선이 붙은 글씨**로 표시됩니다.
5. 메모를 지우려면 **입력창을 비운 채로 저장**하면 됩니다.

> 📌 **참고 사항**
> - 메모는 **최대 1000자**까지 입력할 수 있으며, 입력창 아래에 현재 글자 수가 표시됩니다.
> - 메모는 **저장하는 즉시 서버에 반영**되어, 다른 기기에서 로그인해도 그대로 보입니다.
> - 저장에 실패하면 안내 메시지가 뜨고 **입력창이 열린 채로 유지**되므로, 작성한 내용이 사라지지 않습니다.
> - 메모 편집 중에는 항목을 눌러도 채팅방으로 이동하지 않습니다. (실수로 편집이 닫히는 것을 막기 위함)
> - 이미 북마크한 답변을 **다시 북마크해도 메모는 지워지지 않습니다.**
> - 단, 🔖 아이콘을 다시 눌러 **북마크를 해제하면 메모도 함께 삭제**됩니다.
> - 원본 **채팅방을 삭제하면** 그 방의 북마크와 메모도 함께 사라집니다.

**③ 저장한 답변으로 이동하기**
- 북마크 항목을 클릭하면 원본 채팅방으로 전환되고, 해당 답변 위치로 스크롤·강조됩니다.
- 원본 채팅방이 삭제되었으면 `(삭제된 채팅방)` 으로 표시되며 이동할 수 없습니다.

### 3.4. 답변 일부를 참조해서 다시 묻기

답변 중 특정 문장만 짚어서 "이 부분 더 설명해줘" 처럼 물어볼 수 있습니다.

1. 답변 본문에서 궁금한 부분을 **마우스로 드래그해 선택**합니다.
   (또는 선택한 뒤 **우클릭**해도 됩니다.)
2. 선택 영역 위에 뜨는 **`❝ 참조하기`** 버튼을 누릅니다.
3. 입력창 위에 **`참조 "선택한 내용…" ✕`** 태그가 붙습니다.
4. 그 상태로 질문을 입력하고 전송하면, 선택한 내용이 질문과 함께 모델에 전달됩니다.

| 조작 | 동작 |
|---|---|
| 태그의 `✕` 버튼 | 참조를 뗍니다 |
| 입력창이 빈 상태에서 `Backspace` | 참조를 뗍니다 (버튼을 겨냥하지 않아도 됨) |
| `Esc` | 참조하기 팝업만 닫습니다 (이미 담은 참조는 유지) |

> 📌 **참고 사항**
> - 참조는 **한 번 전송하면 자동으로 해제**됩니다. 다음 질문에 계속 붙이려면 다시 담아 주세요.
> - **다른 채팅방으로 이동하면 참조가 해제**됩니다. 떠나온 방의 답변을 가리키던 내용이기 때문입니다.
> - **응답 중에는 참조를 담을 수 없습니다.** 답변이 끝난 뒤 시도해 주세요.
> - 참조는 **최대 2000자**까지 전달되며, 넘는 부분은 잘립니다.
> - 선택 영역이 **한 답변 안에 온전히 들어 있어야** 합니다. 여러 말풍선에 걸쳐 드래그하면 버튼이 나타나지 않습니다.
> - **생각 과정(🤔) 영역은 참조 대상이 아닙니다.** 답변 본문만 선택할 수 있습니다.
> - 보낸 질문 말풍선에는 참조한 내용이 **인용 블록**으로 함께 표시됩니다.

---

### 3.5. 이전 답변 여러 개를 한 번에 참조하기

문장 일부가 아니라 **답변 전체**를, 그것도 **여러 개** 골라서 물어볼 수 있습니다.
("2번 답변이랑 5번 답변을 비교해줘" 같은 질문에 적합합니다.)

1. 참조하고 싶은 답변 말풍선에서 **마우스 우클릭**을 합니다. (텍스트를 선택하지 않은 상태에서)
2. 말풍선에 **주황색 테두리와 📌 표시**가 붙고, 입력창 위에 **`📌 답변 #2 ✕`** 칩이 추가됩니다.
3. 다른 답변에도 똑같이 우클릭하면 **계속 쌓입니다.**
4. 이미 고른 답변을 **다시 우클릭하면 선택이 해제**됩니다.
5. 질문을 입력하고 전송하면 고른 답변들이 질문과 함께 전달됩니다.

| 조작 | 동작 |
|---|---|
| 답변 말풍선 우클릭 | 담기 / 빼기 (토글) |
| 칩의 `✕` 버튼 | 그 답변만 개별 해제 |
| `전체 해제` 버튼 | 참조가 3개 이상일 때 나타나며, 한 번에 모두 해제 |
| 입력창이 빈 상태에서 `Backspace` | 마지막에 담은 것부터 하나씩 해제 |

> 📌 **참고 사항**
> - 답변은 **최대 10개**까지 담을 수 있습니다.
> - 텍스트를 **드래그한 뒤** 우클릭하면 「❝ 참조하기」 발췌 기능이 뜹니다. 답변 전체를 담으려면 **아무것도 선택하지 않은 채** 우클릭하세요.
> - **발췌 참조와 답변 참조는 함께 쓸 수 있습니다.** 칩 바에 나란히 표시됩니다.
> - **빈 응답 말풍선은 담을 수 없습니다.** (전달할 본문이 없습니다)
> - 참조는 **전송하면 자동으로 해제**되고, **다른 채팅방으로 이동하거나 새 방을 만들면** 사라집니다.
> - **질문을 수정해 대화가 잘리면** 사라진 답변을 가리키던 참조도 함께 정리됩니다.
> - 보낸 질문 말풍선에 **`📌 답변 #2`** 배지로 어떤 답변을 함께 보냈는지 표시됩니다.

### 3.6. 이미지 첨부해서 질문하기 (Vision)

그림·사진·화면 캡처를 올려두고 그것에 대해 물어볼 수 있습니다.

**① 이미지 붙이는 방법 (세 가지 중 편한 것)**
- 입력창 왼쪽의 **📎 클립 버튼**을 눌러 파일 선택
- 이미지를 **입력창 영역으로 끌어다 놓기** (드래그앤드롭)
- 캡처한 이미지를 입력창에서 **`Ctrl` + `V`** 로 붙여넣기

**② 확인하고 보내기**
1. 입력창 위에 **작은 썸네일**이 생기고, 올라가는 동안 "업로드 중…" 이 표시됩니다.
2. 썸네일 오른쪽 위 **✕** 로 개별 제거할 수 있습니다.
3. 업로드가 끝나면 질문을 적고 전송합니다. 보낸 질문 말풍선에도 이미지가 함께 남고, **누르면 원본이 새 탭으로 열립니다.**

| 상황 | 표시 |
|---|---|
| 업로드 중 | 썸네일이 흐려지고 "업로드 중…" |
| 업로드 실패 | 빨간 테두리 + "실패" (마우스를 올리면 원인 표시) |
| 업로드 끝 | 선명한 썸네일 |

> 📌 **참고 사항**
> - **png · jpg · webp · gif** 만 올릴 수 있고, 한 장당 **최대 10MB**, 한 번에 **최대 5장**입니다.
> - **업로드가 끝나기 전에 전송하면 안내가 뜹니다.** 잠시 기다렸다 보내주세요.
> - 이미지는 사내 스토리지(MinIO)에 저장되며, **24시간 뒤 자동 삭제**되도록 설정할 수 있습니다(관리자 설정).
> - 응답 중이거나 다른 채팅방으로 이동하면 첨부가 해제됩니다.
> - ⚠️ **이미지를 이해하려면 Vision 모델이 필요합니다.** 일반 텍스트 모델에서는 이미지가 무시되거나 오류가 납니다. 사이드바에서 Vision 지원 모델을 골라 주세요.

### 3.7. 음성으로 입력하기 (STT)

키보드 대신 말로 질문을 적을 수 있습니다.

1. 입력창 오른쪽의 **🎙 마이크 버튼**을 누릅니다. (처음 누르면 브라우저가 마이크 권한을 물어봅니다)
2. 버튼이 **빨갛게 바뀌고 음파가 움직이면** 듣고 있는 중입니다. 그대로 말씀하세요.
3. 말한 내용이 입력창에 실시간으로 채워집니다.
4. 다 말했으면 **마이크 버튼을 다시 눌러** 멈춘 뒤, 내용을 다듬고 전송합니다.

> 📌 **참고 사항**
> - 이미 적어둔 글이 있으면 **지우지 않고 그 뒤에 이어서** 받아 적습니다.
> - 말이 잠시 끊겨도 **버튼을 누를 때까지 계속 듣습니다.**
> - **전송하거나, 다른 채팅방으로 이동하거나, 새 채팅방을 만들면 자동으로 꺼집니다.**
> - 답변을 🔊 읽어주는 중에 마이크를 켜면 **읽기가 자동으로 멈춥니다.** (스피커 소리를 마이크가 되받아 적는 것을 막기 위함)
> - **Chrome · Edge 에서 동작합니다.** Firefox 등 미지원 브라우저에서는 마이크 버튼이 보이지 않습니다.
> - **`localhost` 또는 `https` 주소에서만 동작합니다.** 다른 기기에서 IP 로 접속하면 마이크 권한이 거부됩니다.
> - ⚠️ 브라우저의 음성 인식은 **음성 데이터를 브라우저 제조사 서버로 보내 처리**합니다. 민감한 내용은 직접 입력해 주세요.

---

### 3.8. 로그인 유지에 대해

- 로그인 상태는 **기본 7일** 유지되며, 브라우저를 닫았다 열어도 남아 있습니다.
- 서비스를 쓰는 동안에는 **유효기간이 자동으로 연장**됩니다. 남은 기간이 절반 아래로 내려가면 서버가 조용히 갱신해 주므로, 계속 쓰는 한 만료로 튕기지 않습니다.
- 그래도 만료되어 로그인 화면으로 나가게 되면, **작성 중이던 문장은 저장**됩니다. 다시 로그인하면 입력창에 그대로 복원되고 안내 메시지가 한 번 표시됩니다.
- 직접 `로그아웃` 버튼을 누른 경우에는 작성 중이던 내용도 함께 지워집니다.

---

### 3.9. 기타 부가 기능

- **음성 읽기 (TTS)**: 답변 하단의 🔊 아이콘을 눌러 답변을 음성으로 듣습니다.
- **질문 수정 및 재개**: 대화 중간의 질문을 수정하면 그 지점부터 답변을 다시 생성합니다.
  (이때 잘려나간 답변에 걸려 있던 북마크와 메모도 함께 정리됩니다.)

## 4. 자주 묻는 질문 (FAQ) 및 에러 대응

| 상황 / 에러 | 원인 및 해결 방법 |
|---|---|
| **응답이 중단됨** | 네트워크 일시 오류 또는 타임아웃. 다시 질문을 전송해 주세요 |
| **권한 없음 (403 Error)** | 스레드 소유권이 다름. 대화방 목록에서 본인 대화방을 다시 선택 |
| **이미 등록된 유저입니다.** | 그 ID 는 이미 사용 중입니다. 다른 ID 로 가입하거나, 본인 계정이면 「로그인」 탭으로 이동하세요 |
| **가입은 되는데 로그인이 안 됨** | 같은 ID 로 재가입해도 비밀번호는 바뀌지 않습니다. 처음 가입할 때 쓴 비밀번호를 확인하세요 |
| **⚠ 세션이 만료되어 다시 로그인했습니다** | 로그인 유효기간(기본 7일)이 지났습니다. 다시 로그인하면 **작성 중이던 문장이 그대로 복원**됩니다 |
| **로그인이 자꾸 풀림 (개발 중)** | 서버 재시작마다 서명 키가 바뀌면 발생합니다. `.env` 의 `AUTH_TOKEN_SECRET` 이 비어 있지 않은지 확인하세요 |
| **이미지 파일만 업로드할 수 있습니다** | png · jpg · webp · gif 만 지원합니다. 다른 형식은 변환 후 올려 주세요 |
| **이미지가 너무 큽니다 (최대 10MB)** | 이미지를 줄여서 다시 올려 주세요 |
| **이미지 저장소에 업로드하지 못했습니다** | MinIO 에 연결할 수 없거나 버킷이 없습니다. 관리자에게 스토리지 상태 확인을 요청하세요 |
| **⚠ 이미지 업로드가 끝난 뒤에 전송해주세요** | 썸네일의 "업로드 중…" 이 사라진 뒤 전송하면 됩니다 |
| **이미지를 올렸는데 답변이 엉뚱함** | 선택한 모델이 Vision 을 지원하지 않을 수 있습니다. 사이드바에서 Vision 모델로 바꿔 주세요 |
| **말풍선의 이미지가 깨져 보임** | 스토리지 링크 유효기간(기본 24시간)이 지났거나 파일이 자동 삭제된 경우입니다 |
| **⚠ 메모 저장에 실패했습니다** | 서버 연결이 끊겼거나 북마크가 이미 삭제된 경우입니다. 입력 내용은 그대로 남아 있으니 잠시 후 `저장`을 다시 눌러 주세요 |
| **⚠ 북마크 서버 연결 실패** | 서버에 연결할 수 없어 브라우저에 저장된 캐시로 동작 중입니다. 이 상태에서는 **메모 수정이 저장되지 않습니다.** 연결이 복구된 뒤 다시 시도해 주세요 |
| **메모가 보이지 않음** | 메모가 없는 북마크는 메모 줄이 표시되지 않습니다. ✎ 버튼을 눌러 새로 작성하세요 |
| **✎ 버튼이 안 보임** | 버튼은 항목에 마우스를 올렸을 때 나타납니다 |
| **응답 중 다른 방으로 이동 불가** | 답변이 끝난 뒤에 이동할 수 있습니다 |
| **「참조하기」 버튼이 안 뜸** | 선택 영역이 한 답변 안에 있는지 확인하세요. 여러 말풍선에 걸치거나 생각 과정 영역을 선택하면 나타나지 않습니다 |
| **참조가 사라졌음** | 전송 후 자동 해제되며, 방을 이동해도 해제됩니다. 정상 동작입니다 |
| **우클릭했는데 📌 대신 「참조하기」 팝업이 뜸** | 텍스트가 선택된 상태였기 때문입니다. 빈 곳을 한 번 클릭해 선택을 푼 뒤 다시 우클릭하세요 |
| **⚠ 참조는 최대 10개까지 담을 수 있습니다** | 상한에 도달했습니다. 칩의 `✕` 나 `전체 해제`로 일부를 뺀 뒤 다시 담아 주세요 |
| **답변을 우클릭해도 담기지 않음** | 빈 응답 말풍선은 전달할 본문이 없어 참조 대상이 아닙니다. 응답 중에도 담을 수 없습니다 |
| **탭 아이콘이 지구본으로 보임** | 브라우저에 남은 이전 파비콘 캐시입니다. `Ctrl` + `Shift` + `R` 로 강력 새로고침하면 🚀 로 바뀝니다 |
| **🎙 마이크 버튼이 안 보임** | Chrome 또는 Edge 로 접속해 주세요. 미지원 브라우저에서는 버튼이 표시되지 않습니다 |
| **⚠ 마이크 권한이 거부되었습니다** | 주소창의 자물쇠 아이콘 → 마이크 → 허용으로 변경한 뒤 다시 눌러 주세요 |
| **⚠ 마이크를 찾을 수 없습니다** | 마이크 장치 연결과 시스템 입력 장치 설정을 확인해 주세요 |
| **음성 인식이 저절로 멈춤** | 전송·방 이동·새 채팅방 생성 시에는 의도적으로 꺼집니다. 그 외라면 마이크를 다시 눌러 주세요 |
