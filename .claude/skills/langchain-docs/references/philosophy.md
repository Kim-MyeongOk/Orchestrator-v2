# Philosophy

원문 : https://docs.langchain.com/oss/python/langchain/philosophy

LangChain은 LLM으로 빌드를 시작하기 가장 쉬운 곳이면서, 동시에 유연하고 운영에 적합하게 만드는
것을 목표로 한다.

## 핵심 신념

- LLM은 강력한 신기술이며, 외부 데이터 소스와 결합하면 더 강력해진다.
- 미래의 애플리케이션은 점점 더 에이전트형(agentic)이 될 것이다.
- 프로토타입을 만들기는 쉽지만, 운영에 투입할 만큼 신뢰성 있는 에이전트를 만들기는 여전히 어렵다.

개발자는 최대한의 유연성/제어를 위해 LangChain을, 또는 계획/파일시스템 도구/서브에이전트/컨텍스트
관리가 내장된 Deep Agents를 선택할 수 있다. 둘 다 LangGraph 위에 구축된다.

## 두 가지 핵심 초점

1. **최고의 모델로 빌드할 수 있게 한다** : 프로바이더마다 다른 API/파라미터/메시지 포맷을 표준화해,
   최신 SOTA 모델로 쉽게 전환하고 락인(lock-in)을 피한다.
2. **모델로 더 복잡한 흐름을 오케스트레이션하기 쉽게 한다** : 모델을 텍스트 생성 이상으로, 다른
   데이터/연산과 상호작용하는 복잡한 흐름의 오케스트레이션에 사용한다. 도구를 정의하고 비정형
   데이터를 파싱/접근하기 쉽게 한다.

## 주요 역사

- **2022-10** v0.0.1 : LLM 추상화 + "Chains"(미리 정해진 연산 단계, 예: RAG)로 출시. 이름은
  "Language" + "Chains".
- **2022-12** : ReAct 논문 기반 범용 에이전트 추가. LLM이 도구 호출을 나타내는 JSON을 생성하고
  파싱.
- **2023-01** : OpenAI Chat Completion API 출시 → 메시지 리스트 입출력으로 진화. JS 버전 출시.
- **2023-03** : function calling 도입 → JSON 파싱 대신 선호되는 도구 호출 방식이 됨.
- **2023-06** : LangSmith 출시(관찰성/평가).
- **2024-01** v0.1.0 : 첫 비-0.0.x 릴리스, 안정성 집중.
- **2024-02** : LangGraph 오픈소스 출시(저수준 오케스트레이션, 스트리밍/durable execution/단기
  메모리/HITL).
- **2024-10** : LangGraph가 단일 LLM 호출 이상의 모든 AI 앱을 만드는 선호 방식이 됨. 대부분의
  chains/agents가 deprecated.
- **2025-10** v1.0.0 : 모든 chains/agents를 LangGraph 기반 단일 고수준 에이전트 추상화로 대체.
  구버전은 `langchain-classic` 패키지로 계속 사용 가능. 표준 메시지 콘텐츠 포맷 도입.
- **2026-03** : Deep Agents 오픈소스 출시(LangGraph 기반 에이전트 하네스, 계획 도구/가상
  파일시스템/서브에이전트 내장).
