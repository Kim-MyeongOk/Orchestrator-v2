# Skill: Client User Guide Synchronizer (클라이언트 사용자 명세서/설명서 동기화)

## Description
개발자가 백엔드/프론트엔드 기능을 새로 추가하거나 기존 동작 방식을 수정할 때, end-user(클라이언트/사용자) 관점에서 시스템을 어떻게 사용해야 하는지 정리한 **사용자 설명서(USER_GUIDE.md)**를 최초 1회 필수 생성하고, 기능 변경 시마다 지속적으로 업데이트하는 스킬입니다.

## Trigger Condition (발동 조건)

다음 경우 중 하나라도 해당할 때 발동합니다:

1. **`USER_GUIDE.md` 파일이 존재하지 않는 상태에서 최초 작업/확인을 진행할 때 (최초 1회 필수 생성)**
2. **사용자 인터페이스(UI) 기능, 화면 레이아웃, 버튼 동작 등이 추가/수정되었을 때**
3. **새로운 사용자 요청 파라미터, 옵션, 입력 방식이 추가되었을 때** (예: reasoning_effort, include_reasoning 옵션 등)
4. **사용자에게 표시되는 응답 형태(NDJSON 스트리밍, 생각 과정 렌더링, TTS, 에러 메시지 등)가 변경되었을 때**
5. **새로운 사용자 작업 흐름(WorkFlow)이나 사용 시 주의사항이 생겼을 때**

## Output Structure & Format (사용자 설명서 작성 양식)

`USER_GUIDE.md` 파일은 비개발자 또는 사용자 관점에서도 직관적으로 이해할 수 있도록 쉬운 단어와 명확한 순서로 작성합니다.

```markdown
# 📖 vLLM Orchestrator Deep Agent - 사용자 이용 명세서 (User Guide)

## 1. 시스템 개요
- **시스템 소개**: 시스템이 제공하는 핵심 기능과 주요 특징 간략 요약
- **주요 제공 기능**: 실시간 답변 스트리밍, 생각 과정(Reasoning) 표시, 대화 요약/압축, 음성 변환(TTS) 등

---

## 2. 화면 구성 및 주요 인터페이스 (UI)
- **채팅 입력창**: 메시지 입력 및 전송
- **모델 & 옵션 설정**: 모델 선택, 추론 강도(Reasoning Effort) 설정 등
- **실시간 스트리밍 창**:
  - 🧠 **생각 과정 표시**: 모델이 사고하는 과정 실시간 출력
  - 💬 **답변 토큰 표시**: 최종 답변 토큰 실시간 출력
- **이전 대화 목록 & 히스토리**: 대화방 선택 및 이전 메시지 조회

---

## 3. 주요 기능별 사용 방법

### 3.1. 질문하기 및 실시간 답변 받기
1. 질문 입력창에 궁금한 내용을 입력하고 `전송` 버튼을 누릅니다.
2. **생각 과정 보기** 옵션이 활성화된 경우, 답변 전 모델의 추론 과정이 먼저 펼쳐집니다.
3. 이어 실시간으로 답변 텍스트가 출력됩니다.

### 3.2. 대화 세션 및 옵션 설정
- **추론 강도 (Reasoning Effort)**: `low` / `medium` / `high` 중 선택하여 답변 깊이 조절
- **대화 압축 안내**: 대화가 길어질 경우 시스템이 자동으로 이전 대화를 요약하며, 요약 완료 알림창이 표시됩니다.

### 3.3. 기타 부가 기능
- **음성 읽기 (TTS)**: 답변 우측 음성 아이콘을 눌러 음성으로 듣기
- **질문 수정 및 질문 재개**: 대화 중간 질문을 수정하면 해당 시점부터 답변을 다시 생성
